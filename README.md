## 📖 About

A REST API in **Node.js + TypeScript** that integrates **Swagger** to
self-document every endpoint, so the contract is always in sync with
the code.

## ✨ Features

- Swagger UI served from the app itself
- TypeScript source with `nodemon` in dev
- Self-documented endpoints
